# Provider

Call the `provider` tool of the `f2r` server once, with no arguments. It opens a dialog where the user picks which provider (NVIDIA or OpenRouter) free-to-review uses first.

Show the tool's result to the user as it is, in English; do not translate it. If it is an error, pass it on in one or two lines and stop. Write anything you add in English too, whatever language the conversation uses.
